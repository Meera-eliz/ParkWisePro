# 🚗 ParkWise – Smart Parking Management System

**ParkWise** is a responsive and interactive web-based application that simplifies parking lot management. It allows users to dynamically create parking slots, park and remove vehicles, reserve spaces, and calculate parking fares in real-time—all through a clean and intuitive interface.

## 🔧 Features

- 🛠 **Custom Slot Creation**: Add parking slots by selecting car types (Hatchback, Sedan, SUV, Truck, Minivan).
- 🅿️ **Vehicle Parking**: Park cars by entering a name and type. The system allocates the nearest available slot.
- 🔄 **Remove Vehicles**: Unpark a vehicle and release the slot.
- ⏳ **Slot Reservation**: Reserve a slot for a specific duration in minutes. The system blocks the slot and automatically releases it after the time expires.
- 💰 **Fare Calculation**: Calculates parking fare based on duration and car type with predefined rates.
- 📊 **Live Status Display**: Visual indicator of slot status (Available = Green, Occupied = Red, Reserved = Yellow).
- 📱 **Responsive UI**: Clean and user-friendly interface that runs directly in the browser.

## 🖥️ Tech Stack

- **HTML** – For structure and layout
- **CSS** – For visual design and dynamic status indicators
- **JavaScript** – For application logic, interaction handling, and timer-based updates

## 📂 File Structure
